# CIDR — Theory

### 1. What is an IP address?

An IPv4 address looks like:

```text
10.0.5.23
```

It identifies an address on a network.

---

### 2. What is `10.0.0.0/16`?

The `/16` tells us:

> **The first 16 bits are used to identify the network.**

An IPv4 address has 32 bits:

```text
32 bits total

[-------- 16 bits --------][-------- 16 bits --------]
       Network part                Host part
```

So `/16` means:

```text
Network | Device/address
  16    |      16
```

You can think of it more simply as:

```text
10.0 | X.X
 ↑      ↑
fixed  can change
```

So the network is:

```text
10.0
```

and the remaining part can vary.

---

### 3. What does "fixed" mean?

Suppose your network is:

```text
10.0.0.0/16
```

Then these can be addresses inside that network:

```text
10.0.0.1
10.0.0.2
10.0.1.1
10.0.5.20
10.0.100.50
10.0.255.200
```

Notice something:

```text
10.0.0.1
10.0.5.20
10.0.100.50
10.0.255.200
  ↑
  10.0 stays the same
```

That's what **"fixed for the network"** means.

The `10.0` portion identifies the network, while the remaining portion identifies different addresses within that network.
